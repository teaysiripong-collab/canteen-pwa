# MEKTEC Canteen Management PWA

เว็บแอปสำหรับจัดการวัตถุดิบและงานปฏิบัติการแคนทีน โดยเน้นการใช้งานบนมือถือ การทำงานแบบ Offline-first และการพัฒนาต่อร่วมกับ ChatGPT/Codex ผ่าน GitHub

## สถานะปัจจุบัน

ระบบเดิมรองรับ:

- เพิ่ม แก้ไข ลบ และค้นหารายการวัตถุดิบ
- IndexedDB สำหรับเก็บข้อมูลในอุปกรณ์
- แจ้งเตือนสต๊อกต่ำและสินค้าหมด
- สแกน Barcode บนอุปกรณ์ที่รองรับ
- Export/Import JSON
- ตั้งค่า REST Sync endpoint
- PWA และ Service Worker

รายละเอียดเพิ่มเติมอ่านได้ที่ [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md)

## วิธีให้ Codex เริ่มงาน

ใช้คำสั่งรูปแบบนี้:

```text
อ่าน AGENTS.md, PROJECT_CONTEXT.md, TASKS.md และ CHANGELOG.md ก่อน

สรุปความเข้าใจของโปรเจกต์และระบุไฟล์ที่เกี่ยวข้องกับงาน
จากนั้นทำเฉพาะงาน: <ระบุงาน>

ห้ามลบฟีเจอร์เดิมโดยไม่ได้รับอนุญาต
เมื่อเสร็จให้อัปเดต TASKS.md และ CHANGELOG.md
พร้อมสรุปวิธีทดสอบ
```

## วิธีทำงานที่แนะนำ

1. หนึ่งงานหลักต่อหนึ่ง Branch
2. ให้ AI อ่านเอกสารกลางก่อนทุกครั้ง
3. ให้ Codex แก้โค้ดและเปิด Draft Pull Request
4. ตรวจ Diff และทดสอบก่อน Merge
5. อัปเดต Task และ Changelog ทุกงาน

รายละเอียดขั้นตอนอ่านได้ที่ [`docs/AI_WORKFLOW.md`](docs/AI_WORKFLOW.md)

## หลักการสำคัญ

- Mobile-first
- ภาษาไทยสำหรับผู้ใช้งาน
- เขตเวลา `Asia/Bangkok`
- ห้ามเก็บ Secret หรือ Token ใน Repository
- ห้ามแก้ยอดสต๊อกโดยไม่มีประวัติรายการ
- ฟีเจอร์ใหม่ต้องไม่ทำให้ของเดิมเสีย
- ข้อมูลราคา สูตร พนักงาน และยอดจริงต้องมาจากผู้ใช้งานหรือแหล่งข้อมูลจริง

## Roadmap แบบย่อ

1. ทำระบบเดิมให้เสถียรและแปล UI เป็นภาษาไทย
2. รับเข้า เบิก โอน Lot วันหมดอายุ และ FEFO
3. สูตรอาหารและเมนูรายสัปดาห์
4. สั่งซื้อแยก Vendor และ Export ให้ฝ่ายจัดซื้อ
5. Dashboard รายงาน สิทธิ์ผู้ใช้ และ Audit trail

ดูรายละเอียดและสถานะล่าสุดได้ใน [`TASKS.md`](TASKS.md)
